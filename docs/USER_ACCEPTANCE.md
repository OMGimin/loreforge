# 직접 사용·창작 결과 확인

작성일: 2026-10-20. 자동 검사와 에이전트의 본문 대조를 사람의 직접 평가와 구분한다. 실제 답변을 받기 전에는 통과로 표시하지 않는다. 발표자료 제작과 5분 리허설은 현재 필수 완료조건에서 제외한다.

## 개인 원고로 이해하기

개인 이해·평가 자료는 **개인 확인에 사용할 기존 설정집**이다. 실제 분석·생성·검토·1회 수정·재검토와 비교 자료 준비를 마쳤다. 최종 지적 2건을 남겼다. 2026-10-20 직접 답변으로 구조 제안의 유용성과 설명문 형태 유지 선호를 확인했으며 후속 답변에서 원래 의도가 대체로 유지됐다는 평가를 받았다. 구체적인 선택지는 열린 채로 두며 전체 채택과는 구분한다. 원고가 어떻게 설정 후보·조건·근거로 정리되고 검토·수정에 연결되는지 직접 살펴본다.

- 특정 작품에 맞춘 기능·프롬프트 변경은 하지 않는다. 공개 키워드·가상 설정 fixtures는 유지한다.
- 개인 원문·생성물·실행 DB·평가 원문은 Git에서 제외한 `runtime/`에만 보관한다. 공개 문서에는 개인 원문을 옮기지 않는다.
- 분석과 생성 모두 `trace=False`로 실행한다. 개인 자료의 LangSmith 추적을 켜지 않는다.
- 지원 길이 안에서 검증하고 긴 문서를 조용히 잘라내거나 자동 요약해 전체 검증으로 표현하지 않는다.
- 모델 실행 결과와 원문·초안·수정본·근거를 직접 읽은 판단을 구분한다. API 호출이 성공해도 창작 품질이 검증된 것은 아니다.

## 작성자 사용성 피드백과 보완

2026-10-20 작성자는 내부 문단 번호의 의미를 이해하기 어렵고, 설정 본문에 작성 목적·원문 유지 여부를 설명하는 문장이 섞여 있다고 지적했다. 앞선 구조적 유용성·의도 유지 평가와 별개인 사용성 문제로 기록한다.

- 문단 번호: 내부 ID 대신 문서 내 순서에 따른 ‘1번 문단’을 표시한다. 근거 버튼은 ‘수정본 · 2번 문단’처럼 문서 버전을 함께 표시하고 문서 제목도 유지한다. 번호 안내와 글자 크기를 보완했다. 내부 ID·저장 데이터·근거 연결은 변경하지 않는다.
- 검증: 문단 순서·문서 버전·없는 참조의 표시 검사 3건 통과. 저장된 개인 결과에서 검토 근거와 그래프 근거를 눌러 각각 해당 문단으로 이동하는 것을 확인했다. 실제 사용자 재확인은 아직 받지 않았다.
- 본문 지침: 작업 설명 대신 설정 내용을 바로 쓰도록 생성·수정 지침을 보완했다. 공개 입력의 실제 생성·수정 2회에서 안내 서문이 없고 미정 선택지가 유지되는 것을 확인했다. 기존 개인 결과는 자동 재작성하지 않는다.
- 작업 위치: `fix/readable-proposals` 별도 작업 트리에서 수정·검증한다. 기존 main과 원본 결과는 보존한다.

## 처음 보는 사람의 사용성

개인 원고를 알고 있는 작성자의 자체 평가와 처음 보는 동료의 평가는 구분한다. 동료 확인이 가능하면 공개 입력 `유리 사막, 기억을 파는 상인, 사라진 달`로 시작한다. 화면 안내만으로 입력→재료 정리→생성→관계·근거 탐색→채택까지 진행하고 막힌 화면·버튼 이름과 기대 행동을 적는다.

기존 결과 탐색에는 추가 모델 호출이 없다. 새 분석·생성·이어쓰기는 실제 API 비용이 발생하므로 모의 시연과 구분한다. 모의 브라우저의 동작 검사는 완료했지만 처음 보는 사람의 사용성 평가는 **미실시**다.
