# 직접 사용·창작 결과 확인

작성일: 2026-10-20. 자동 검사와 에이전트의 본문 대조를 사람의 직접 평가와 구분한다. 실제 답변을 받기 전에는 통과로 표시하지 않는다. 발표자료 제작과 5분 리허설은 현재 필수 완료조건에서 제외한다.

## 개인 원고로 이해하기

개인 이해·평가 자료는 **개인 확인에 사용할 기존 설정집**이다. 실제 분석·생성·검토·1회 수정·재검토와 비교 자료 준비를 마쳤다. 최종 지적 2건을 남겼으며 사람 평가·채택은 미확인이다. 원고가 어떻게 설정 후보·조건·근거로 정리되고 검토·수정에 연결되는지 직접 살펴본다.

- 특정 작품에 맞춘 기능·프롬프트 변경은 하지 않는다. 공개 키워드·가상 설정 fixtures는 유지한다.
- 개인 원문·생성물·실행 DB·평가 원문은 Git에서 제외한 `runtime/`에만 보관한다. 공개 문서에는 개인 원문을 옮기지 않는다.
- 분석과 생성 모두 `trace=False`로 실행한다. 개인 자료의 LangSmith 추적을 켜지 않는다.
- 지원 길이 안에서 검증하고 긴 문서를 조용히 잘라내거나 자동 요약해 전체 검증으로 표현하지 않는다.
- 모델 실행 결과와 원문·초안·수정본·근거를 직접 읽은 판단을 구분한다. API 호출이 성공해도 창작 품질이 검증된 것은 아니다.

| 확인 항목 | 직접 확인 결과 |
|---|---|
| 설정 후보와 AI 추측의 차이를 이해할 수 있었나? | 미확인 |
| 선택한 보호 조건이 실제 요청·검토에 반영되었나? | 미확인 |
| 본문·항목·관계의 근거가 원문의 의미와 맞았나? | 미확인 |
| 검토 지적이 실제 충돌·설명 부족인지, 창작 선택인지 구별할 수 있었나? | 미확인 |
| 초안·수정본 중 채택할 버전과 이유를 설명할 수 있었나? | 미확인 |
| 미해결 질문이 수정·채택 뒤에도 남는 이유를 이해했나? | 미확인 |

## 처음 보는 사람의 사용성

개인 원고를 알고 있는 작성자의 자체 평가와 처음 보는 동료의 평가는 구분한다. 동료 확인이 가능하면 공개 입력 `유리 사막, 기억을 파는 상인, 사라진 달`로 시작한다. 화면 안내만으로 입력→재료 정리→생성→관계·근거 탐색→채택까지 진행하고 막힌 화면·버튼 이름과 기대 행동을 적는다.

기존 결과 탐색에는 추가 모델 호출이 없다. 새 분석·생성·이어쓰기는 실제 API 비용이 발생하므로 모의 시연과 구분한다. 모의 브라우저의 동작 검사는 완료했지만 처음 보는 사람의 사용성 평가는 **미실시**다.

## 같은 초안의 수정 전후 판단

같은 실행의 초안과 수정본을 읽는다. 별도로 생성한 두 이야기를 비교하지 않는다. 가능하면 어느 것이 수정본인지 보기 전에 판단한다.

| 항목 | 판단 및 근거 문단 |
|---|---|
| 지적한 문제가 해결되었나? | 미확인 |
| 유지할 조건을 지켰나? | 미확인 |
| 이야기의 핵심 의도를 불필요하게 바꾸지 않았나? | 미확인 |
| 새로운 모순이나 설명 부족이 생겼나? | 미확인 |
| 어느 버전을 채택할 것인가? 이유는 무엇인가? | 미확인 |

모델 재검토에서 지적이 없어졌다는 사실만으로 통과 처리하지 않는다. 공개 폭풍 도시의 설명 보충은 에이전트가 관찰한 결과이고, 개인 원고의 판단과 사람의 채택 평가는 아직 남아 있다.
