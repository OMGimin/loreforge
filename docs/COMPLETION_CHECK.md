# MVP 완성 기준 확인

2026-10-20 갱신. 기능 구현, 실제 API 실행, 사람의 사용·창작 평가는 구분한다. 새 기능·팔레트 변경·배포는 이번 마감 작업에 포함하지 않는다. 직접 발표하지 않을 가능성을 반영해 발표자료 제작과 5분 리허설은 현재 필수 완료조건에서 제외하고 결과보고·실행·검증 문서는 유지한다.

| 기준 | 확인한 내용 | 남은 확인 |
|---|---|---|
| 처음부터 만들기 | 첫 화면·분석 뒤 다음 행동·좁은 화면 이동과 초점을 모의 브라우저에서 확인 | 처음 보는 사람의 사용성 평가는 미실시 |
| 검토 이해 | 기대 분류·쟁점 수·근거를 고정한 새 사례 6건이 v3·v4에서 각각 일치 | 다양한 입력의 일반화, 사람의 판단 |
| 수정의 유용성 | 같은 폭풍 도시 초안·수정본의 설명 보충을 에이전트가 대조 | 사용자 의도 보존·부작용·채택 이유에 대한 직접 평가 |
| 그래프·선택·복원 | 자동·브라우저 검사, 실제 첫 설정·채택 후 이어쓰기, 저장된 실제 결과 탐색 확인 | 개인 원고에서도 결과와 근거를 직접 읽기 |
| 추적 | LangSmith 원격 API에서 root 2개·총 10개 span과 모델·분기·MCP·사용량 대조 | LangSmith 웹 화면 로그인 후 표시 |
| 재현 | 비밀값·기존 DB·의존성 폴더 없이 별도 설치, 타입·빌드·모의 HTTP 흐름 확인 | 다른 OS 환경은 미확인 |
| 개인 이해·평가 | 개인 확인에 사용할 기존 설정집으로 진행하기로 결정 | 실제 생성·검토·1회 수정·재검토와 비교 자료 준비 완료. 사람 평가·채택 미확인 |
| 결과보고·제출 | 실행·검증·한계 문서 유지 | 수정 안내·공개 범위·실제 제출 상태 확인 |

최종 통합 검사는 80개 테스트·타입 검사·빌드·Git diff 검사를 통과했다. 독립 설치본의 60개 통과는 그 시점의 코드로 확인한 기록이며, 최초 구현의 31개와도 구분한다. 실행별 증거는 [구현 결과](RESULTS.md)를 기준으로 한다.

## 실행 원칙

- 공개 검증은 공개 키워드·가상 설정과 공개 fixtures로 재현한다. 새 6건의 기대 판단은 호출 전에 고정했고, v4 반복은 같은 사례의 회귀 확인으로 구분한다.
- 개인 원고는 이해·평가용이다. 특정 작품에 맞춘 기능·프롬프트 변경을 하지 않는다. 개인 원문·생성물·DB·평가 원문은 ignored `runtime/`에만 저장하고 `trace=False`로 실행한다. 공개 fixtures는 유지한다.
- 근거 참조의 존재와 의미의 타당성은 별도 확인한다. 에이전트의 대조를 사람 평가로 표시하지 않는다.
- LangSmith 원격 API 확인과 웹 화면 로그인, 로컬 완료와 공개 접근·최종 제출을 각각 구분한다.
- 기존 5분 원고는 선택 참고자료로 보존한다. 발표 제외는 현재 작업 범위의 결정이며 공식 면제 확인으로 표현하지 않는다.
- 로컬 커밋은 작업 범위와 검증을 확인한 뒤 구분한다. 추가 푸시·제출은 별도 요청을 따른다.

## 작업 분담

화면 안내, 검증 도구·회귀 검사, 독립 설치 확인을 나누고 실제 실행과 문서 정합성은 통합해 확인한다. 각 하위 작업은 `gpt-6.1-sol` 모델을 명시해 요청했고 도구가 수락했다. 실제 런타임 모델의 별도 증명과 총괄 모델 설정은 확인되지 않았다.
