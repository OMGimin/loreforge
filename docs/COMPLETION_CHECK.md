# MVP 완성 기준 확인

2026-10-20 갱신. 기능 구현, 실제 API 실행, 사람의 사용·창작 평가는 구분한다. 별도 작업 트리에 승인된 검토 전용 흐름과 그래프 표시 범위를 구현했다. 현재 코드의 검사와 실제 원고 검토 증거를 아래 과거 증거와 구분하며 팔레트 전면 변경·배포는 포함하지 않는다. 직접 발표하지 않을 가능성을 반영해 발표자료 제작과 5분 리허설은 현재 필수 완료조건에서 제외하고 결과보고·실행·검증 문서는 유지한다.

검토 전용 추가 당시 Python 검사 98개·프런트엔드 검사 7개·타입 검사·빌드가 통과했다. 과잉 지적과 연결 배치 보완 이후 Python 105개·프런트엔드 11개·타입·빌드·diff 검사가 통과했다. 상세 기록은 RESULTS.md를 따른다. 실제 검토 실행·화면 확인의 상세 증거와 한계는 [구현 결과](RESULTS.md)를 따른다. 기존 main에는 병합·푸시하지 않았다. 새 사람 평가나 전체 품질 통과를 확인한 것은 아니다.

검토 전용 추가 이전 통합 검사는 80개 테스트·타입 검사·빌드·Git diff 검사를 통과했다. 이 수치는 새 목적 탭·검토 전용·그래프 가독성 변경의 검증 결과가 아니다. 독립 설치본의 60개 통과는 그 시점의 코드로 확인한 기록이며, 최초 구현의 31개와도 구분한다. 실행별 증거는 [구현 결과](RESULTS.md)를 기준으로 한다.

표의 남은 확인이 모두 이번 구현의 필수 조건은 아니다. 다른 OS 지원과 광범위한 품질 일반화는 확장 검증이다. LangSmith 웹 화면은 선택 확인이며 원격 수신 자체는 API 조회로 검증했다. 수정 공지는 확보 시 대조하고 푸시·제출은 별도 승인 범위다. 개인 원고의 구조적 유용성과 설명문 형태 유지 선호는 직접 확인했다. 원래 의도가 대체로 유지됐다는 작성자 평가를 받았으며 구체적인 선택지는 열린 채로 둔다. 전체 채택 판단은 아직 받지 않았다. 작성자 평가를 처음 보는 사람의 사용성 평가로 바꾸어 기록하지 않는다.

## 실행 원칙

- 공개 검증은 공개 키워드·가상 설정과 공개 fixtures로 재현한다. 새 6건의 기대 판단은 호출 전에 고정했고, v4 반복은 같은 사례의 회귀 확인으로 구분한다.
- 개인 원고는 이해·평가용이다. 특정 작품에 맞춘 기능·프롬프트 변경을 하지 않는다. 개인 원문·생성물·DB·평가 원문은 ignored `runtime/`에만 저장하고 `trace=False`로 실행한다. 공개 fixtures는 유지한다.
- 검토 전용은 원고→분석·선택 조건 확인→검토 1회→쟁점 확인·보고서 내보내기로 끝낸다. 쟁점 유형·원문/조건 인용·이유·수정 방향·문단 이동을 제공하고 원문을 수정하거나 자동 채택하지 않는다. completed 또는 needs_attention을 구분하고 쟁점이 없어도 정확성을 보증하지 않는다.
- 근거 참조의 존재와 의미의 타당성은 별도 확인한다. 에이전트의 대조를 사람 평가로 표시하지 않는다.
- LangSmith 원격 API 확인과 웹 화면 로그인, 로컬 완료와 공개 접근·최종 제출을 각각 구분한다.
- 기존 5분 원고는 선택 참고자료로 보존한다. 발표 제외는 현재 작업 범위의 결정이며 공식 면제 확인으로 표현하지 않는다.
- 로컬 커밋은 작업 범위와 검증을 확인한 뒤 구분한다. 추가 푸시·제출은 별도 요청을 따른다.

## 작업 분담

화면 안내, 검증 도구·회귀 검사, 독립 설치 확인을 나누고 실제 실행과 문서 정합성은 통합해 확인한다. 각 하위 작업은 `gpt-6.1-sol` 모델을 명시해 요청했고 도구가 수락했다. 실제 런타임 모델의 별도 증명과 총괄 모델 설정은 확인되지 않았다.
