# LoreForge 구현 결과

작성일: 2026-10-20

## 현재 상태

로컬 웹 MVP를 구현하고 공개 가상 입력으로 실제 OpenAI API 흐름을 확인했다. 키워드→생성·검토→최대 1회 수정→그래프→채택→이어쓰기, 기존 설정 입력, Markdown 내보내기, 이력 복원을 제공한다. 최종 보완 후 공개 입력의 LangSmith 원격 기록을 API로 조회해 역할·수정 분기·MCP·사용량을 대조했다. 브라우저의 LangSmith 로그인 세션은 없어 웹 화면 직접 확인은 남아 있다.

화면은 Vue 3·TypeScript·Vite·Cytoscape.js, 서버는 Python 3.11·FastAPI·Pydantic·SQLite·LangGraph로 구성했다. 설정 담당은 `gpt-5.4-mini`, 창작·검토 담당은 `gpt-5.4`를 사용한다. 실제 응답 모델·프롬프트 버전·토큰·호출 수를 기록한다.

## 완성 기준 보완 결과 — 2026-10-20

- 첫 사용 안내: 재료 정리 뒤 요청 입력으로 이동, 생성 후 검토 패널로 이동, 최종 문서 보기 버튼을 추가했다. 좁은 화면의 키보드 초점과 패널 이동도 브라우저에서 확인했다. 기존 녹색·금색 팔레트를 유지했다.
- 검토 요청: 초안·수정본 검토 양쪽에 사용자의 실제 요청을 전달한다.
- 미해결 쟁점: 의도 질문과 수정 가능한 문제가 함께 있어도 질문은 원래 문서·근거 스냅샷으로 남는다. 수정·채택·이어쓰기로 자동 해결하지 않으며, 현재 문서의 쟁점과 분리해 표시한다. 이전 초안을 확정 기준에 넣지 않는다. 질문 응답을 통한 자동 해결 기능은 이번 범위에 없다.
- 추적: 실제 서버가 하위 span의 `trace_id`만 지정한 요청을 400으로 거절했다. 기본 수집 API가 `parent_run_id`에서 계층을 계산하도록 수정했다. 실패 기록을 보존하고 공개 입력 1건만 추가 실행했다.
- 검사 환경: 자동 테스트는 로컬 키 유무와 관계없이 LangSmith 추적을 끈다. ZIP처럼 `.git` 없는 배포본은 코드·타입·빌드 검사를 수행하고 Git diff 검사만 생략한다.

### 최종 실제 실행과 추적

유리 사막 실행 당시 모델 흐름은 성공했지만 LangSmith 하위 단계 전송은 실패했다. 폭풍 도시 실행에서는 경고 없이 완료했고, 원격에서 분석 root와 생성 root, 총 10개 span을 조회했다. 모델 5회, MCP stdio 조회, `revise`/`finish` 분기를 확인했으며 모델명·입출력 토큰·최종 상태가 로컬과 일치했다. 입력 본문은 비어 있고 메타데이터·출력에는 실행 정보만 있었다. SDK가 프로젝트명·Git revision·단계 깊이를 추가하는 것도 검사 범위에 반영했다. 이 결과는 원격 API 조회 증거이며 LangSmith 웹 화면의 로그인 확인을 대신하지 않는다.

새 평가 6건의 v3·v4 실행과 위 워크플로를 합해 23회 모델 호출, 입력 60,250 / 출력 18,627토큰을 관측했다. 실제 청구 금액으로 환산하지 않았다. 재시도는 없었다.

추적 검증기는 보고서에 해당하는 분석·생성 root를 모두 요구한다. root 누락, 전송 경고, 보고서와 DB의 불일치를 로컬에서 먼저 실패 처리한다. 일부 성공한 root만 검사해 전체를 통과시키지 않는다. 보완한 검증기로 같은 원격 기록을 다시 조회해 root 2개의 통과를 확인했으며, 이 재조회는 모델 호출을 추가하지 않았다.

로컬 증거는 Git에서 제외한다.

- `runtime/verification-20261020T034548.796296Z/report.json`: 최초 새 사례 6건.
- `runtime/verification-20261020T035108.165527Z/report.json`: v4 첫 생성·이어쓰기·새 사례 6건. 같은 폴더의 추적 검사는 하위 단계 누락 실패를 기록했다.
- `runtime/verification-20261020T035320.416504Z/report.json`: 추적 보완 후 생성·수정·재검토. `trace-verification.json`은 원격 조회 통과 기록.
- `runtime/final-check/human-review.md`: 같은 폭풍 도시 초안·수정본의 직접 비교 자료.

### 수정 전후의 관찰과 사람 평가

새 폭풍 도시 초안에서는 서진이 도시를 떠나지 못한다고 끝맺지만, 서진의 이주 계획과 그 선택의 이유가 충분히 제시되지 않았다. 수정본 p3은 떠날 계획을, p5는 누이의 기억과 계속 배달해야 할 이유를 보충했다. 두 본문에서 에이전트가 확인한 변화다. 직접 평가는 익숙한 개인 원고로 진행하도록 대상을 바꿨으며 아래 기록과 구분한다.

| 비용 범위 | 호출 | 입력 / 출력 토큰 | 모델 호출 시간 합계 |
|---|---:|---:|---:|
| 공통 준비 분석 | 1 | 1,184 / 553 | 4.042초 |
| A: 최초 초안 생성 | 1 | 1,587 / 2,217 | 31.228초 |
| B: 같은 초안 생성+검토·수정·재검토 | 4 | 13,259 / 5,012 | 62.496초 |

B는 A 비용을 포함한다. 전체 72.107초에는 추적·MCP 등 모델 외 실행 시간도 포함되어 위 모델 시간 합계와 다르다. 화면의 현재 문서 쟁점은 1→0으로 바뀌었지만 창작 품질 보증이나 사람 평가 결과로 표현하지 않는다.

### 개인 기존 원고의 이해·평가

별도로 지정한 기존 원고로 공통 API의 분석·생성·검토·1회 수정·재검토를 실행했다. 특정 작품용 시스템 프롬프트·기능·공개 fixtures는 변경하지 않았다. 원문은 보존하고 제안본과 비교 자료를 ignored `runtime/final-check/`에만 저장했다. 분석·생성 모두 추적을 끄고 채택 상태는 `pending`으로 유지했다.

5회 호출·재시도 0회, 입력 73,035 / 출력 25,522토큰, 213.684초를 기록했다. 최종 상태는 `needs_attention`이며 지적 2건이 남았다. 앞의 공개 검증 23회와 구분한 개인 실행이다. 초안의 유효하지 않은 관계 5개는 제외·경고했고, 수정본 자체의 18개 항목·24개 관계는 참조 검증을 통과했다. 원문과 합친 그래프는 38개 항목·44개 관계이며 기본 30개 표시 상한과 필터를 안내한다.

실제 웹에서 결과 선택·그래프 관계 선택·근거 문단 이동을 확인했다. 2026-10-20 원고 작성자는 안내한 전환 제안 문단에 대해 구조 제안이 유용하고 설명문 형태를 유지하겠다고 답했다. 이어 원래 설정 의도가 대체로 유지됐으며 구체적인 선택지는 열린 채로 두겠다고 답했다. 이는 비블라인드·설명 개입이 있는 작성자 평가이며 전체 제안의 채택이나 모든 지적의 정확성을 확인한 것은 아니다. 에이전트가 원문과 대조한 결과, 설명문 형태로 요약되어 원래 문체와 세부 장면 일부가 줄었고 모호한 표현도 남았다. 또한 모델이 제안본의 항목 누락을 지적했지만 원문 그래프에는 이미 존재하는 항목이 있어 지적의 범위를 다시 판단해야 한다. 유효한 참조·정상 실행·그래프 상태가 창작 결과의 완전성이나 검토의 정확성을 보장하지 않는 사례로 남긴다.

이 실행에서 같은 경고가 여러 줄 반복돼 본문을 밀어내는 표시 문제를 확인했다. 같은 내용은 건수와 함께 묶고 이전 초안을 포함한 실행 전체 경고임을 명시했다. 원시 경고는 삭제하지 않았다. 표시 수정 뒤 타입·빌드를 다시 통과했고 저장된 실제 결과 화면에서 경고 5건이 한 줄로 보이는 것을 확인했다. 추가 모델 호출은 없었다.

## 본문 표현 보완 — 별도 작업 트리

작성자의 사용성 피드백에 따라 `loreforge-v5-content-first`에서 창작·수정 본문에 작성 목적·검토용 안내·원문 유지 보고를 넣지 않도록 했다. 설명문·설정집 형식은 유지할 수 있고 미정인 설정 선택지도 그대로 남긴다. 상태 안내는 화면에서 제공한다. 기존 저장된 본문을 사후 삭제·변형하지 않는다.

공개 가상 설정 ‘안개 항구의 사서와 등대지기의 지도’를 기존 OpenAI 키로 생성·수정 각 1회 검증했다. 입력 3,342 / 출력 5,459토큰, 재시도 없음, LangSmith 추적 없음이다. 두 응답 모두 작업 설명 없이 설정·사건으로 시작했고 어부·약사 중 미정인 동료 선택을 유지했다. 수정 시험은 작업 설명과 이동 경로 누락을 의도적으로 넣은 가상 초안이다. 모델이 실제로 발견한 문제처럼 표시하지 않는다. 수정본은 다음 날 아침의 도보 경로를 보충했다. 두 결과의 문서·그래프 참조 검증 경고는 없었다.

이는 창작 지침의 좁은 실제 API 확인이며 v5 전체 파이프라인의 재검증이나 일반 품질 보증은 아니다. 앞선 v4 전체 실행·LangSmith 결과와 구분한다. 백엔드 80개와 문단 표시 검사 3개, 타입·빌드 검사를 통과했다. 실제 응답과 호출 기록은 작업 트리의 ignored `runtime/writer-content-report.json`에 보존한다. 변경은 `fix/readable-proposals`에서 확인하며 기존 main·개인 결과·채택 상태는 유지한다.

## 같은 초안의 수정 전후 관찰

초기 키워드 실행의 D0를 그대로 A로, 검토 후 수정한 D1을 B로 비교했다. D0는 ‘폭풍 경보가 울리면 해 뜨기 전까지 등대에 인계한다’는 규칙을 제시했지만 실제 경보 발생을 명시하지 않았다. D1은 사이렌이 울렸다는 장면을 추가해 규칙 적용 이유를 드러냈다. 코드 작성 에이전트가 두 본문을 직접 대조한 관찰이며 별도의 사람 평가가 완료된 것은 아니다.

| 항목 | A: 최초 생성 | B: 같은 초안+검토·수정·재검토 |
|---|---:|---:|
| 생성 이후 호출 수 | 1 | 4 |
| 입력 토큰 | 1,539 | 13,354 |
| 출력 토큰 | 2,975 | 5,363 |
| 모델 호출 경과 시간(초) | 27.240 | 51.681 |
| 해당 버전의 AI 검토 쟁점 | 설명 부족 1건 | 기록된 쟁점 0건 |

공통 준비 분석은 별도 1회·입력 812/출력 991토큰·5.706초다. B는 A의 생성 비용을 포함한다. 쟁점 감소는 동일 모델의 재검토 관측값이며 정밀도·전체 일관성 보증이 아니다. 문체·설정 변경의 선호 판단과 블라인드 사람 평가는 남아 있다.
