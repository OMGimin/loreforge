# 설정공방 LoreForge — 기존 5분 발표 원고

이 원고는 기존 초안으로 보존한다. 직접 발표하지 않을 가능성을 반영해 발표자료 제작과 5분 리허설은 현재 필수 완료조건에서 제외했다. 아래 시간 배분은 필요할 때 참고할 계획이며 실제 리허설 기록이 아니다. 결과보고·실행·설계·검증 문서는 유지한다.

공개 입력의 실제 API 실행과 웹 동작을 확인했고 LangSmith 원격 API로 root 2개·총 10개 span을 대조했다. 웹 화면 로그인 후 표시는 미확인이다. [구현 결과](RESULTS.md)의 최신 수치와 한계를 사용하며 모의 응답을 실제 AI 출력처럼 설명하지 않는다.

## 1장 · 흩어진 아이디어를 세계관으로 — 40초

설정공방 LoreForge는 키워드 몇 개부터 시작할 수 있는 AI 창작 웹 서비스다. 처음부터 완성된 설정집을 요구하지 않는다. 창작 과정에서 늘어나는 인물·규칙·사건의 관계를 살펴보고, 새 이야기가 기존 조건과 충돌하는지 근거를 확인할 수 있도록 만들었다.

핵심은 긴 글 한 번을 생성하는 데서 끝내지 않고, 생성한 설정을 검토하고 채택해 다음 이야기의 기준으로 이어가는 것이다. 그래프는 인물과 사건의 연결을 탐색하는 화면이며, 정확성을 보장하는 장치는 아니다.

## 2장 · 키워드에서 이어쓰기까지 — 90초

공개 시연 입력: `폭풍 도시, 기억을 보관하는 등대, 마지막 배달부`

1. 재료를 입력하고 정리한다. 조건 지정 없이도 생성할 수 있음을 보여준다.
2. 저장된 생성 결과의 본문과 그래프를 전환한다. 노드 또는 관계 하나의 근거 문단을 연다.
3. 검토 쟁점과 수정본을 확인한다. 쟁점이 없으면 정상 결과라고 설명하고 오류를 연출하지 않는다.
4. 최종 결과를 채택하고 ‘이어쓰기’를 선택한다. 채택한 결과가 다음 기준에 포함됨을 보여준다.

긴 API 응답을 기다리지 않도록 미리 저장한 실제 결과를 사용할 수 있다. 이때 저장된 실행을 재생한다고 밝힌다. 모의 모드만 검증했다면 그 상태를 그대로 설명한다.

## 3장 · 내가 설계하고 검토한 핵심 — 80초

- 본문·항목·관계·근거를 하나의 문서 형식에 저장한다. 같은 데이터로 본문 화면·그래프·내보내기를 구성해 버전 불일치를 줄인다.
- 입력 원문, AI 제안, 채택 결과를 분리한다. 원문과 실행 당시 기준은 덮어쓰지 않고 채택한 최종 결과만 이어쓰기에 포함한다.
- 설정 정리→창작→검토를 역할별 프롬프트와 출력 형식으로 나누고, LangGraph로 수정 최대 1회라는 종료 조건을 구현한다.
- 근거 조회는 읽기 전용 MCP로 처리한다. 문단이 존재하는지와 실제로 주장을 뒷받침하는지는 구분한다.

수업 Base에서는 FastAPI·LangGraph·SSE·MCP의 연결 방식을 참고했다. 제품의 문서 계약·검토 기준·채택 상태·그래프는 주제에 맞게 구성했다. AI의 구현 도움을 받았으며, 발표에서는 직접 확인한 코드와 판단 근거를 설명한다.

## 4장 · 무엇을 검증했나 — 50초

[구현 결과](RESULTS.md)의 실제 검증 결과만 사용한다.

- 자동 검사: 기준과 제안의 분리, 근거 참조, 수정·재시도 상한, 저장·복원.
- 브라우저: 입력·생성·본문/그래프·근거·채택·이어쓰기·새로고침.
- 실제 AI: 검증한 경우에만 모델명·실행 날짜·호출·토큰·남은 오류를 제시한다.
- 비교: 같은 초안을 공유한 수정 전후 비교만 A/B로 제시한다. 모의 데이터나 테스트에 심은 오류를 자연 생성 품질 결과로 계산하지 않는다.

## 5장 · 한계와 다음 단계 — 40초

현재는 짧은 입력의 로컬 단일 사용자 서비스다. 전체 기준을 넣기 때문에 긴 설정집은 범위를 줄여야 한다. 창작과 검토가 같은 모델을 사용해 오류를 공유할 수 있고, 문단 근거가 존재해도 해석이 틀릴 수 있다. 그래프도 모든 관계를 빠짐없이 추출한다는 보장은 없다.

다음 단계는 실제 사용 사례를 모아 오탐과 누락을 확인하는 것이다. 이후 긴 문서 검색이 필요해질 때 RAG를, 수동 관계 정리가 필요해질 때 그래프 편집을 검토한다.

## 필요할 때 참고할 리허설 체크

- 총 300초. 세부 배분은 40+90+80+50+40초.
- 현재 10/22 13:00 준비 기준은 구현·결과보고·실행·검증 문서에 적용한다. 발표자료와 리허설은 필수 작업에서 제외했다. 공식 일정 변경 여부는 별도 확인.
- 키·비공개 원문·추적 정보가 화면에 나오지 않는 공개 입력을 사용한다.
- 네트워크 실패에 대비해 공개 입력의 저장 결과와 캡처를 준비한다.
- 실제 발표 시간 측정과 최종 제출은 수행하지 않았다. 개인 이해·평가는 개인 확인에 사용할 기존 설정집으로 별도 준비 중이며 원문·생성물은 공개 자료에 넣지 않는다.
