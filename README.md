# 설정공방 · LoreForge

**키워드 몇 개부터 기존 설정집까지, 흩어진 아이디어를 일관된 세계관으로 발전시키는 AI 창작 웹 서비스.**

창작자는 키워드·메모·설정집 중 가진 재료만 입력하면 된다. 설정 담당·창작 담당·검토 담당 AI가 초안을 만들고 입력 조건과 내부 일관성을 검토한다. 사용자가 채택한 결과만 다음 확장의 기준으로 사용할 수 있다. 기존 설정집은 필수 입력이 아니다. 본문과 관계 그래프를 함께 보면서 인물·사건·규칙을 탐색하고, 근거와 검토 결과를 확인한다.

## 현재 상태

- 2026-10-20: 웹 기반 MVP, 그래프 탐색과 문서 구조, 3일 구현·평가 계획 정리.
- **현재 저장소에는 기획 문서만 있으며 실행 가능한 서비스는 아직 없다.**
- 테스트·시연: 공개 키워드 3개로 첫 설정 만들기, 채택 후 이어쓰기, 짧은 가상 설정집 확장.
- 모델은 보유한 **OpenAI API 키**로 연결할 계획이다. 키 설정과 실제 호출·성능 검증은 개발 단계에서 진행한다.
- 기존 AI 구독을 사용하는 CLI 연결은 후속 확장 후보다. 이번 MVP는 API 방식이다.

## 3일 MVP

1. 입력창 하나에 키워드·메모·설정집을 넣는다. `.txt`/`.md` 가져오기와 반드시 지킬 조건은 선택 사항이다.
2. 입력에서 정리한 설정 후보·조건을 확인한다. AI의 추측은 확정 설정으로 저장하지 않는다.
3. 새 입력에 요청이 없으면 첫 설정 초안 하나를 제안한다. 이어쓰기는 다음 사건을 기본 제안하고, 요청이 있으면 그 내용으로 구체화한다.
4. 입력 조건·채택한 설정과의 충돌, 초안 내부 모순, 설명 부족을 근거 위치와 함께 검토한다.
5. 필요할 때 최대 1회 수정하고 재검토한다. 미해결 문제와 판단 불가를 그대로 표시한다.
6. 본문·그래프를 전환하고 노드나 관계를 선택해 상세 내용·근거·관련 검토 결과를 확인한다.
7. 문서 단위로 채택·보류하고 Markdown으로 내보낸다. 채택한 결과는 ‘이 설정 이어쓰기’로 다음 작업의 기준에 포함할 수 있다. 입력 원문과 이전 결과는 보존한다.

## 계획한 구성

| 영역 | 선택 |
|---|---|
| 화면 | 데스크톱 브라우저용 Vue 3 웹 화면: 자료 목록·본문/그래프·상세/검토 |
| 그래프 | Cytoscape.js, 읽기·탐색 전용, 본문·항목·관계·근거를 담은 공통 문서에서 표시 |
| 서버 | FastAPI |
| 실행 흐름 | LangGraph, 역할 3개, 순차 검토·수정 |
| 모델 | OpenAI API, 하나의 모델로 시작하고 모델 ID는 설정으로 관리 |
| 근거 조회 | 버전·문단 ID가 있는 입력/채택 설정 저장소 + 읽기 전용 MCP 도구 1개 |
| 저장 | SQLite, 입력·기준 설정·초안·검토·채택 상태와 버전별 그래프 데이터 구분 |
| 진행 표시 | 단계별 SSE 이벤트 |
| 평가 | 기능 검증 우선, 같은 초안의 단일 생성과 검토 루프 비교는 보너스 목표 |

브라우저에서 로컬 개발 서버에 접속하는 웹 앱으로 구현한다. Obsidian 설치나 플러그인은 필요하지 않으며, 외부 배포는 이번 3일 범위에 포함하지 않는다.

## 원문과 키 관리

원본 설정집·개인 입력은 `local/`, 실행 데이터는 `runtime/`, 내보낸 결과는 `exports/`에 둔다. 이 경로와 `.env`는 Git에서 제외한다. API 키는 서버 환경에서만 읽고 브라우저에 전달하지 않는다.

테스트에는 공개용 키워드와 짧은 가상 설정을 사용한다. 특정 작품을 미리 테스트 대상으로 정하지 않고 공통적인 창작 흐름을 검증한다. LangSmith는 공개용 가상 입력 1건으로 실행 흐름을 확인하는 우선 검증 항목이다. 추적은 기본 비활성으로 두고 해당 확인 작업에서만 명시적으로 켠다. 비공개 원문 추적은 별도 선택이다.
