# 설정공방 · LoreForge

**뿌리 스토리에서 세계관을 확장하고, 설정의 일관성을 검토하는 멀티에이전트 창작 도구.**

창작자가 설정과 확장할 내용을 입력하면, 설정 담당·창작 담당·검토 담당 AI가 근거를 공유하며 확장안을 만든다. 충돌 가능성과 설명이 부족한 부분을 보여주고, 창작자가 채택할 내용을 선택한다.

## 현재 상태

- 2026-10-20: 이름, 기획, 3일 MVP 범위 및 평가 계획 정리.
- **현재 저장소에는 기획 문서만 있으며 실행 가능한 서비스는 아직 없다.**
- 첫 적용 사례: 사용자가 게임으로 구상한 **강호행**의 뿌리 스토리 구체화.
- 첫 모델 연결: 사용자가 보유한 **OpenAI API 키**. 실제 키 설정·API 호출·성능 검증은 아직 하지 않았다.
- 기존 AI 구독을 사용하는 CLI 연결은 후속 확장 후보다. 이번 MVP는 API 방식이다.

## 3일 MVP

1. 뿌리 스토리를 텍스트로 입력하거나 `.txt`/`.md` 파일로 가져온다.
2. 원문 문단과 연결된 설정 후보를 확인하고 이번 작업에서 지킬 조건을 선택한다.
3. 인물·사건·분기 중 하나의 확장 요청으로 초안을 생성한다.
4. 검토 결과에서 충돌 후보, 설명 부족, 확인할 질문, 근거 문단을 확인한다.
5. 필요할 때 최대 1회 수정하고 재검토한다. 미해결 문제는 그대로 표시한다.
6. 최종 제안을 채택 또는 보류하고 Markdown으로 내보낸다. 뿌리 원문은 보존한다.

## 계획한 구성

| 영역 | 선택 |
|---|---|
| 화면 | Vue 3 기반 단일 작업 화면 |
| 서버 | FastAPI |
| 실행 흐름 | LangGraph, 역할 3개, 순차 검토·수정 |
| 모델 | OpenAI API, 하나의 모델로 시작하고 모델 ID는 설정으로 관리 |
| 근거 조회 | 문단 ID가 있는 원문 저장소 + 읽기 전용 MCP 도구 1개 |
| 저장 | SQLite, 원문·초안·검토·채택 상태 구분 |
| 진행 표시 | 단계별 SSE 이벤트 |
| 평가 | 같은 입력의 단일 생성과 검토 루프 비교 |

이 표는 구현 계획이며 현재 구현 상태를 의미하지 않는다.

## 원문과 키 관리

원본 설정집·개인 입력은 `local/`, 실행 데이터는 `runtime/`, 내보낸 결과는 `exports/`에 둔다. 이 경로와 `.env`는 Git에서 제외한다. API 키는 서버 환경에서만 읽고 브라우저에 전달하지 않는다.

공개 테스트에는 별도로 만든 짧은 가상 설정을 사용한다. 실제 강호행 원문이나 생성 결과의 공개 여부는 별도로 정한다. LangSmith 외부 추적은 MVP 필수가 아니며 기본 비활성으로 계획한다.
